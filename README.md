# Neon Outlaw

A neon-soaked, top-down open-city driving game. Explore an endlessly generated city, weave through traffic, evade the police, grab pickups, and chase a new high score.

## Play

- **WASD / Arrow keys** — drive
- **Space** — handbrake / drift
- **E** — enter or exit a vehicle
- **Shift** — nitro
- **P / Escape** — pause
- **M** — toggle sound

Touch controls are provided on mobile devices. Scores are saved locally in your browser.

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Deployment

This is a static Vite app and can be deployed directly to Vercel. The production build command is `npm run build`, with `dist` as the output directory.
